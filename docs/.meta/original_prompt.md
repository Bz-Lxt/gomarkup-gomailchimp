帮我用Go语言实现一个企业级多租户智能邮件营销（EDM）与高并发群发履约系统

实用价值：邮件营销是独立站、SaaS 软件拉新和唤醒老用户最核心的商业手段。该项目不仅包含邮件模板的在线设计，核心挑战在于如何在保证不被各大邮件服务商（如 Gmail, Outlook）拉黑的前提下，平稳、高速地将数万封带有追踪链接的邮件发送出去，并精准统计送达率、打开率和点击率。

前端页面 (React / Vue 3 + 拖拽模板 + 实时漏斗大屏)：

- 邮件可视化拖拽编辑器 (Email Builder)：支持用户通过拖拽组件（文本、图片、按钮、分割线），在线组合 HTML 邮件模板，并支持插入动态占位符（如 Hi, {{ .UserName }}）。
- 营销活动（Campaign）控制台：配置目标客群导入（Excel/CSV）、发送策略（立即发送/定时发送/分批渐进式发送）。
- 数据流向实时漏斗大屏：利用 Echarts 炫酷渲染本次群发的流式漏斗图：发送总数 -> 投递成功 -> 邮件打开 -> 链接点击 -> 退订/投诉。

Go 后端核心实现：

- 多通道高并发群发管道 (Smtp Pipeline)：不能直接用一个循环死板地发邮件。后端需要基于 Go 的 worker pool 机制，启动成百上千个并发 Goroutine 异步消费邮件任务队列，支持多 SMTP 账号或第三方服务（如 AWS SES）的动态负载均衡。
- 精准分布式限速器 (Rate Limiter)：各大邮件厂商对单 IP/单域名的每小时接收量有严格限制。后端需手写或集成基于 令牌桶（Token Bucket） 的限速器。一旦发现 Gmail 通道达到频率上限，自动将 Gmail 的任务挂起或降速，而 Outlook 通道保持全速发送。
- 邮件状态追踪像素与反向重定向网关：
  - 打开率统计：后端在 HTML 邮件末尾动态插入一个 1x1 像素的透明图片（如 `<img src="https://api.com{{.TaskID}}.png" />`）。当用户打开邮件、客户端加载该图片时，后端网关瞬间捕获请求并更新数据库。
  - 点击率统计：将邮件中的所有外部链接改写为后端的代理重定向链接（如 `https://api.com`），用户点击时，后端记录点击行为再 302 重定向到原网站。
- 动态弹回（Bounce）与退订黑名单处理：解析邮件发送失败的退信回执（如信箱不存在、被拒收），利用状态机自动将该邮箱标记为"死信"，并加入黑名单隔离区，防止下次继续发送导致域名信誉度崩塌。

文件数与代码量：约 30+ 个 Go 文件，代码量 5000 - 8000 行。
